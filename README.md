This is just a small trackmania plugin which allows you to vote to skip/restart maps on a server without having to go into your menu settings. 

Current features:
Provides a window which contains 4 buttons to Skip/Restart/VoteYes/VoteNo
Remembers window position & size between loads
Allows you to hide the window title by setting a flag in settings
Allows you to set window opacity to fit in with your other plugins
